# BIOMED Orthopedics — Website

A 3D, interactive website for BIOMED Orthopedics (est. 1989), a Mumbai-based manufacturer of orthopaedic implants and surgical instruments.

## Features
- Three.js 3D hero scene: a realistic titanium locking plate/screw implant fixed to a translucent holographic bone, with floating technical spec annotations and a scanning sweep effect
- Full product catalog (90+ implants across 8 categories) sourced from biomedorthopedics.com, with search, category filters, and a "Read More" spec-sheet modal for each product
- Interactive 3D globe with pins for all international client countries (India HQ + Afghanistan, Malaysia, Kenya, Ukraine, Turkey, Nigeria, Djibouti, Sudan)
- Real company info: About/Vision/Mission/Core Values, instrument set brochures, contact details, and enquiry form

## Usage
This is a single self-contained `index.html` file — no build step required. Open it directly in a browser, or serve the repo with GitHub Pages (Settings → Pages → Deploy from branch `main` / root).

## Tech
Vanilla HTML/CSS/JS + [Three.js](https://threejs.org/) (r128, via CDN). No frameworks, no build tools.
